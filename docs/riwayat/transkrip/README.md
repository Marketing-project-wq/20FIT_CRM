# Transkrip Sesi

Salinan mentah percakapan sesi agen. **Kosong untuk Sprint 1–3I.**

Untuk periode itu yang tersimpan hanya laporan penutup (`sprint-*/02-laporan.md`) —
bukan transkrip penuh. Langkah antara, percobaan yang dibuang, dan pertimbangan yang
tidak masuk laporan sudah tidak bisa dipulihkan.

## Konvensi

Nama berkas: `<sprint>-<YYYY-MM-DD>.md`, mis. `3j-2026-08-12.md`.

Salin **seluruh** percakapan sebelum sesi ditutup. Sekali ditutup tanpa disalin, isinya
hilang permanen — itu sudah terjadi sembilan kali.

## Sebelum commit

Baca ulang dan hapus setiap PII pelanggan: nomor telepon, alamat email, nama lengkap,
`identity_key`, isi `reason_detail`. Transkrip ikut ter-push ke GitHub. Email staf
internal boleh bila relevan pada keputusan.
