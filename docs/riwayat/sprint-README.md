# Arsip Prompt per Sprint

Tiap folder `sprint-*/` memuat prompt persis yang diberikan ke Claude Code, apa adanya.
Beberapa memuat berkas tambahan: balasan atas gerbang migrasi, atau tambahan tugas yang
menyusul.

**Ini rekaman, bukan klaim hidup.** Prompt lama memuat angka dan asumsi yang sudah bergeser —
termasuk model deploy yang belakangan terbukti keliru (T-18). Jangan perbaiki isinya; nilai
arsipnya justru pada apa yang diyakini saat itu.

Untuk keadaan sekarang, baca `PANDUAN-LANJUTAN.md` dan register di repo.
